# navidrome client by thepmsquare

> 📌 versioning: see [CHANGELOG.md](./CHANGELOG.md).

## about

an android client for self-hosted [navidrome](https://www.navidrome.org/) compatible music servers.

## android specifications

- **minimum sdk**: android 7.0 (nougat, api level 24)
- **target sdk**: android 15 / 16 (api level 35 / 36)
- **compile sdk**: 36
